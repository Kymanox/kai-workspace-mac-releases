# Kai Workspace macOS releases

Public signed and notarized macOS installers, updater metadata, and release assets for Kai Workspace.

For a first installation, download the `Kai-Workspace-<version>-mac.dmg` installer from the latest stable release. Existing installations use `latest-mac.yml`, the ZIP package, and associated blockmap files for updates.

Published tags and asset filenames are compatibility interfaces. Preserve existing releases and their signed assets when changing repository organization or naming.
